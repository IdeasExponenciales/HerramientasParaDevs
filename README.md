# HerramientasParaDevs
Listado de herramientas para Desarrolladores de Software


- SERPER
 - Search Engine Results Pager
 - Herramienta para poder obtener resultados de búsquedas en formato JSON, tiene un retraso de respuesta de hasta 2 segundos.
 - https://serper.dev/

- MoltBot
 - Antes OpenClaw y ClawBot, herramienta para organizar y ejecutar agentes en tu propia computadora local con acceso a tu información por medio de Telegram, Whatsapp
 - https://moltbot.org/
 - https://github.com/moltbot/moltbot
